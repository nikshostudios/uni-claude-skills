Martin's Odyssey

Everything you need to study, write, and build with Claude Code, on one page. 39 skills, a life vault, and a seven-day flight plan. None of it has to happen at once. One small step a day, and by next week this is second nature.

step 0 — before anything

Have Claude Code installed and logged in (check with claude --version). These commands are for the Mac/Linux terminal; on Windows, run them inside WSL (wsl --install once, then reopen the terminal). Never paste passwords into any chat.

launch — two commands, ever

1 · the skills — day 1

t=$(mktemp -d) && curl -fsSLo $t/i.sh https://raw.githubusercontent.com/nikshostudios/uni-claude-skills/v1.0.0/install.sh && bash $t/i.sh && rm -rf $t

2 · the vault (your obsidian system) — day 3

t=$(mktemp -d) && curl -fsSLo $t/v.sh https://raw.githubusercontent.com/nikshostudios/uni-claude-skills/v1.0.0/install-vault.sh && bash $t/v.sh && rm -rf $t

First command = all 39 skills (Day 1). Second = your vault (Day 3, no rush — and if you already keep an Obsidian vault, skip it; /guide-me knows how to adopt the structure into yours without touching your notes). Then open Claude Code anywhere and type: /guide-me. It interviews you about your semester and takes it from there. Prefer to read before running? Clone the repo and run bash install.sh --local.

the flight plan

One small step a day. That's the whole trick.

You don't need to learn 39 skills. You need one new habit a day for a week, and each habit pays off the same day you learn it. Everything else is reference for later.

day 1 — ignition

Install, and win once.

Run the first install command. Open Claude Code anywhere, type /guide-me, and have one real conversation about the thing due soonest. That's it. No vault yet, no systems.

type this/guide-me — then answer its three questions honestly.
day 2 — first orbit

Study something properly.

Pick the topic confusing you most right now and have it taught to you, with a quiz at the end. Works with nothing installed: paste your lecture notes or name the topic. Got yt-dlp? Then Claude can also find the best video and pull its transcript first.

say this"Teach me ER-diagrams, here are my lecture notes." (upgrade: "find the best video on it first")
day 3 — the ship

Install your vault. Get interviewed.

Run the second install command, open the folder in Obsidian, then let Claude interview you — three questions by default, deeper only if you want. It builds the vault around your answers and tells you which skills fit your life. Already keep a vault? Say "adopt the starter structure" instead; nothing of yours gets touched.

say this"onboard me into my vault", inside the vault folder
day 4 — daily rhythm

Learn the two session habits.

End today's work session with /wrap. Claude files what happened into your vault so tomorrow starts warm. And if a long session ever gets sluggish, /checkpoint hands it to a fresh session without losing anything. These two habits are what make everything compound.

say this"wrap" at the end of a session · "checkpoint this" when a session drags
day 5 — cargo

Write something that sounds like you.

Next essay or discussion post: one sentence from you, and Claude drives the whole chain — grills your argument, builds from your own notes, then edits the draft so it reads like you on a good day. One habit; the pipeline is Claude's job.

say this"Grill me on my essay argument, then run the writing pipeline from my notes."
day 6 — heavy lift

Run a project like a professional.

Any coding assignment or group project, one sentence: Claude specs it, splits it into tickets, builds methodically, and reviews the architecture before you submit. This is what makes group work stop being chaos.

say this"to-spec what we discussed, break it into tickets, then implement ticket one."
day 7 — deep space

Pick one power-up. Ignore the rest.

Codex second opinions, a real browser for your agent, persistent memory. Pick whichever solves a problem you actually hit this week; the section below explains each. Everything else can wait a month.

say this"Which power-up fits what I struggled with this week?"
the pipelines

Three chains to memorize. (Or just ask.)

study a topic
/yt-search→/yt-transcript→/teach

Find the best video, pull its transcript and digest, get taught until it sticks. Then /wrap files what you learned into your vault.

write an essay
/grill-me→/writing-fragments→/writing-beats→/writing-shape→/unslop

Stress-test the argument, mine your notes, build the arc, draft with you steering, then edit the result into your natural voice.

ship a group project
/grill-me→/to-spec→/to-tickets→/implement→/improve-codebase-architecture

The idea becomes a spec, the spec becomes tickets your teammates can split, and the build gets an architecture review before anyone submits.

week 2+ — power-ups

The bigger rig, one piece at a time.

Separate installs that upgrade Claude Code itself. Pick one when you hit the problem it solves, never all at once.

Setup: npm i -g @openai/codex, codex login, then a codex companion plugin via /plugin. Two frontier models agreeing on a diagnosis beats one; disagreeing is where it gets interesting.

someday — the hangar

Advanced ships. Park them for now.

Five repos worth starring today and exploring in a month or three, once the basics are muscle memory. Each one is a serious upgrade in one dimension.

chaseai-yt/claudex-loop

Two AI models review and then build each other's plans, so whoever wrote a plan never grades it. For when a project really matters.

 tt-a1i/archify

Architecture, workflow, and sequence diagrams as self-contained HTML with motion. Made for the exact diagrams system-design coursework keeps asking for.

 herdrdev/herdr

A runtime for coordinating multiple coding agents, for the day one Claude isn't enough. Think big group projects with parallel workstreams.

 firecrawl/anydoc

Converts Word, PowerPoint, Excel, PDF, and EPUB into clean Markdown. Feed any course material into Claude or your vault in seconds.

 deepseek-ai/deepseek-harness

"Everything is a plugin." A modular base for assembling your own agent setup. The deep end of the pool; visit when you're ready to build your own rig.
the ground rule

Tools for learning, not shortcuts past it.

This kit helps you understand material, structure your thinking, polish your production, and run projects like a professional. It will not help you evade AI detectors, fabricate citations, or submit work you can't explain. That refusal is built into the skills themselves. If your university asks for AI-use disclosure, disclose. The goal is graduating smarter, with a rig you'll still use at your first job.
