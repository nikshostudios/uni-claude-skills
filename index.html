cluster 01 — study & learning

Learn it properly, faster.

Click any card for the exact thing to say to Claude.

say this

"Teach me database normalization — I have a quiz on Friday."

Runs a real teaching loop: explain → example → you try → correct. Use before exams, after confusing lectures, or when a topic won't stick.

say this

"Find me the best recent videos explaining REST APIs."

Returns a ranked list with views, channel size and dates. The views-to-subscribers ratio is a hidden-gem detector.

say this

(just paste the YouTube link — that's the whole trigger)

Files a timestamped transcript into ./transcripts/, then offers a TL;DR, key concepts with timestamps, and a 5-question recall quiz.

say this

"wait-what" — when an explanation didn't land. "zoom-out" — when you're lost in code details.

Two tiny skills that fix the two classic stuck-states: bad explanation, missing context.

cluster 02 — writing

Essays that sound like you.

The writing pipeline builds essays from your thinking — and the cleanup skills strip the AI flavor from anything drafted.

say this

"I have an essay due on digital privacy and a pile of rough notes — run the writing pipeline."

Fragments finds your good raw material, beats arranges it into a journey, shape drafts paragraph-by-paragraph with your approval. The result is your essay, structured — not a generated one.

say this

"Unslop this discussion post" · "Run humanizer on my report intro."

Humanizer is built on Wikipedia's signs-of-AI-writing guide: kills inflated symbolism, rule-of-three, em-dash overuse, filler. For editing your writing — not for disguising work that isn't yours.

say this

"Grill me on my capstone proposal before I pitch it to my professor."

Relentless, specific questioning. The gaps it finds are the ones your grader would have found. /grill-with-docs also records the decisions as docs.

say this

"I need a creative angle for my final-year project topic."

Researches real exemplars from far-apart domains and recombines them against your problem. Every idea is banked to ./_creativity/ so next session starts where this one ended.

cluster 03 — project workflow

Group projects, under control.

The discipline cluster: turn vague project ideas into specs, tickets, and finished work — and never lose a long session again.

say this

"We've talked enough — to-spec this, then break it into tickets."

The core delivery pipeline. Specs stop group-project scope drift; tickets make work divisible among teammates; implement executes without wandering.

say this

"Checkpoint this session" — then paste the output into a new session.

Learn these two early. Long Claude sessions degrade; checkpoint captures every decision so a fresh session picks up mid-stride.

say this

"This capstone is way bigger than one session — wayfinder it."

Wayfinder maps huge work as decision tickets. Graph structures a high-stakes task as a multi-agent workflow. Triage grinds through GitHub issues/PRs in a disciplined loop.

say this

"ask-matt: I have a messy idea and a deadline — which skill do I use?"

ask-matt routes you to the right workflow. write-a-skill teaches Claude to build new skills — your toolkit grows with your degree.

cluster 04 — coding & design

Projects that don't look like homework.

Info-systems coursework ships web apps. These make yours look and read like products.

say this

"Build the dashboard for my project — read frontend-design first so it doesn't look templated."

frontend-design sets aesthetic direction; impeccable audits hierarchy, spacing, accessibility, motion. Demo-day difference-makers.

say this

"Pick me a palette and font pairing for a fintech-feeling project" (ui-ux-pro-max).

ui-styling builds shadcn/Tailwind components; ui-ux-pro-max is a local database of styles, palettes and fonts; design-system keeps multi-page projects consistent.

say this

"Review my project's architecture before I submit — give me the visual report."

Finds structure problems and improvement opportunities. Also: /setup-ts-deep-modules wires dependency-cruiser for clean TypeScript boundaries.

say this

"Write Playwright tests for my web app's signup flow."

Real end-to-end tests impress graders and catch demo-day bugs before the demo.

cluster 05 — documents

Submissions that look the part.

say this

"Here's my assignment brief [attach PDF] — build the submission document from my draft answers."

Maps every rubric line to a section so nothing is missed, renders Mermaid diagrams (WBS, Gantt, risk quadrants) as real vector graphics, and produces pixel-perfect PDF plus Word. Integrity rules are built in — it formats and structures work you own.

say this

"I can't decide the project scope without my professor — to-questionnaire it."

Produces the exact questions to send. loop-me interviews you about any workflow you wish were automated — then you build it together.

the pipelines

Skills compose. Start here.

study a topic
/yt-search→/yt-transcript→/teach

Find the best video, pull its transcript and digest, then have the concept taught until it sticks. One evening, one topic, actually learned.

write an essay
/grill-me→/writing-fragments→/writing-beats→/writing-shape→/unslop

Stress-test the argument, mine your notes, build the arc, draft with you steering, then strip anything that sounds machine-made.

ship a group project
/grill-me→/to-spec→/to-tickets→/implement→/improve-codebase-architecture

Idea → spec → tickets your teammates can split → disciplined build → architecture review before submission.

the ground rule

Tools for learning, not shortcuts past it.

This pack helps you understand material, structure your thinking, polish your production, and manage projects like a professional. It will not help you evade AI detectors, fabricate citations, or submit work you can't explain — assignment-creator refuses that by design. If your university asks for AI-use disclosure, disclose. The point is graduating smarter, with a toolkit you'll still use at your first job.
